# TechFlow Solutions 🚀

Sistema de gerenciamento ágil de tarefas logísticas desenvolvido com **Python** e **Flask**, utilizando **Bootstrap** para a interface visual e **Pytest** para testes unitários automatizados.

## 🛠️ Tecnologias Utilizadas
* Python 3.10
* Flask (Framework Web)
* Pytest (Testes Automatizados)
* Bootstrap 5 (Estilização)
* GitHub Actions (Integração Contínua - CI)

## 🚦 Status do Projeto
*Os testes automatizados estão configurados e ativos via pipeline de CI!*

2. Instale as dependências necessárias:
